## Prompt

Create one consistent Code Engineer AI Wayfarer identity repeated in exactly eight sequential full-body assemble-action frames on a perfectly uniform chroma green background. The character is a clearly human, non-robot professional with mature friendly expression, 2.8–3.2-head-tall premium chibi proportions, dark sculpted hair, warm coral workshop jacket, ivory shirt, tan practical trousers, boots, and brass/teal tools. Include the same compact wooden/brass workbench in every frame.

Arrange frames left-to-right, top row then bottom row:

1. Ready beside the bench.
2. Reach toward the component.
3. Place the component.
4. Align it with both hands.
5. Tighten with a hand tool.
6. Inspect the connection.
7. Lift/show the assembled device.
8. Settle into a quiet completed stance.

Every frame uses the identical character face, hair, outfit, tool, bench, camera, scale, and planted-foot baseline. Motion must be articulated through arms, hands, torso lean, gaze, and tool interaction, never whole-body bobbing.

## Chroma and packing constraints

- Background is exactly flat `#00ff00`, uniform edge-to-edge: no gradient, texture, floor, horizon, reflection, cast shadow, or contact shadow.
- Do not use chroma green in the character, bench, clothing, or tools.
- Exact 4×2 grid, generous separation, no cell dividers, no overlap, all silhouettes fully inside cells.
- No text, letters, numbers, labels, UI, logo, watermark, extra people, robots, screen face, antenna, armor, or mechanical limbs.
- Keep one stable 3/4 orthographic view and common visible foot/workbench contact baseline.
